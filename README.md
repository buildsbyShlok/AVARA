## ✦ Overview

AVARA is a full-stack travel platform built around immersive discovery, curated destinations, and community-driven exploration.

## ✦ Features

- 🌍 Discover and explore destinations
- 🔎 Search and filter travel listings
- 🏡 Host and manage destinations
- 👤 User authentication and profiles
- ⭐ Reviews and ratings
- 🖼️ Destination galleries
